## Product and supported release target

AuthZest's product direction is FastAPI source-based authentication/authorization analysis and
AI-assisted patching. Version 0.1.0 concentrates on **GET object-ownership authorization defects**
in an explicitly selected, self-contained single Python application file in another local folder.
The user provides an explicit policy; declarations alone do not establish intended access rules.

| Area                     | Required 0.1.0 behavior                                                                                                                                                                                                                                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Source and setup         | One selected FastAPI application file, in-memory data, explicit app entry and supported pinned dependencies. Initial active environment: macOS arm64, Python 3.12 source installation and Docker Desktop.                                                                  |
| Authentication boundary  | Use the reviewed synthetic or specified identity setup. Check anonymous denial when policy requires it; this does not validate a login system or establish real identity authenticity.                                                                                     |
| AI artifacts             | Generate new bounded HTTP PoC request **data** and model-authored replacement source. Selecting a registered after-template does not satisfy generation.                                                                                                                   |
| Independent verification | Run the exact before/after source in isolated A guests and capture bounded HTTP observations through trusted B observers. Expected policy answers remain on the host, independent of AI output.                                                                            |
| Correction and recovery  | Review the exact diff, apply only after current explicit decisions, verify the private copy, then separately approve the final single-file original application. Preserve backup, refuse changed originals and support inspected recovery without overwriting later edits. |
| Presentation             | CLI progress and a complete result JSON. External-workflow GUI scope is saved-result viewing, with unsupported, not-run, unknown, failure and recovery states visible.                                                                                                     |

Maintain 4–8 independently reviewed cases, including one designated regression, normal owner access,
non-owner denial and anonymous denial where applicable, plus public intent or a reviewed
not-applicable reason. Record case authorship, identity assumptions and before/after expectations.
Concrete policy answers and image/runtime inputs still require review for the actual trial.
Finite matching observations support these cases; they do not certify the whole application.

## Deferred work

- General FastAPI vulnerability analysis and JWT, OAuth, login, session or identity-provider flaws.
- Multi-file/package/`src` layouts, project dependency installation, databases and external services.
- Other HTTP methods, arbitrary request scripts and execution of model-authored Python/pytest PoCs.
- External active-GUI control, expanded native/cross-platform active runtime, extra adapters and
  comparative benchmark expansion.

The delivered fixed demonstration, v1.0 proposal path, v1.1 test interface and T/A/B foundation stay
intact with their own limits. The HTTP-data-only A/B route needs **its own explicit request, profile,
result and operator contracts**, which are not implemented by this freeze. Do not silently convert
old requests or manufacture T IDs, counts, pytest success or live evidence to fit that route.
