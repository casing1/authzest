## Current tooling warning

The frontend lock and guarded formatter/configuration bytes match the reviewed preflight. Standalone
picomatch is 4.0.7; Prettier 3.10.1 also bundles a separate 2.3.2 copy. GitHub
[withdrew its advisory](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), while the
[CVE record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2026/112xxx/CVE-2026-112366.json)
remains PUBLISHED. The record disagreement and absence of an inspected fixed release remain tracked
in [#171](https://github.com/casing1/authzest/issues/171). The three named brace-expansion fixes under
[#89](https://github.com/casing1/authzest/issues/89) remain present.

The proposed disposition is a candidate-specific warning and continued tracking of development-tool
availability exposure. Untrusted configuration/patterns used through a changed checkout, direct
Prettier/editor/API invocation, or concurrent file changes outside guard assumptions can cause work
to stall. Use reviewed checkouts and the [guarded formatting commands](../development/FORMATTING.md).
Selected native inventories show no separately packaged matcher/formatter entry or frontend
node_modules; that observation does not prove their absence from every binary byte or accept residual risk.
