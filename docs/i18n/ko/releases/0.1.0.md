# AuthZest 0.1.0

[문서](../INDEX.md) · [English](../../../releases/0.1.0.md) · 한국어

릴리스 노트 준비일은 **2026-11-23 KST**입니다. 이 문서는 과제 정식판의 예정 범위를 설명하며,
파일이 있다는 사실은 발행 완료를 뜻하지 않습니다. 실제 태그·파일·체크섬은
[GitHub Releases](https://github.com/casing1/authzest/releases)에서 확인하세요.
[후보 판단](0.1.0-READINESS.md)은 별도로 관리합니다.

## 이번 판의 기능

- **오프라인 FastAPI 목록.** 스캔 대상 저장소를 import하거나 실행하지 않고 지원하는 앱/router
  등록, prefix와 의존성 선언을 찾습니다. 읽기 쉬운 CLI 또는 JSON으로 소스 위치·진단·부분 분석
  상태를 표시합니다.
- **Codex 보조 방어 테스트·수정 생성.** 직접 관리하는 합성 보관 노트 사례에서 정확한 소스·정책
  요청을 미리 보고, 교체 가능한 Codex adapter에 새 회귀 테스트와 가용성 규칙 파일 하나의 수정을
  요청합니다. 변경 없음과 unknown도 정상 결과입니다.
- **검토한 비공개 복사본 작업.** 런타임·공유·복사·before·정확한 diff·적용·after·복구를 각각
  검토합니다. 검토한 네트워크 차단 Linux guest에서 생성 테스트와 유지 중인 대조 항목 7개를
  검사합니다. 적용은 새 비공개 복사본만 변경합니다.
- **로컬 영한 GUI.** 정적 라우트·저장 JSON을 조회하거나, 명시적으로 같은 owner-read 엔진과 현재
  직접 입력하는 결정을 활성화합니다. 코드·차이·관찰·복구를 확인하고 전체 결과를 내려받습니다.
  종료된 실행은 반복 조회를 멈춥니다. 웹사이트 배포는 필요하지 않습니다.

이 사례의 의도된 대조는 **before 정책 일치 6/7 → after 7/7**이며, 소유자의 보관 노트 조회
(HTTP 403 → 200)를 포함합니다. 생성 테스트 결과·독립 대조·정리·복구도 확인하세요.
이 예상값은 새 모델 응답의 성공 보장이 아닙니다.

## 설치 경로 선택

| 경로                                               | 지원 범위                                                                                |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| editable 소스·UI extra·lock 기반 프런트엔드 빌드   | 현재 로컬 대시보드, 검토한 런타임을 갖춘 POSIX non-frozen 설치의 활성 owner-read GUI/CLI |
| 일반 Python wheel 또는 소스에서 설치한 pipx CLI    | CLI 명령, wheel에는 대시보드 자산 미포함                                                 |
| 태그별 Linux x64·macOS arm64·Windows x64 실행 파일 | 정적 스캔·오프라인 미리보기, frozen 실행 파일의 활성 owner-read 수정 미지원              |

[README](../README.md)와 [과제 시연](../guides/COURSE_DEMO.md)에서 시작하세요.
활성 흐름에는 Python 3.12, 신뢰한 Codex CLI **0.153.0**, 기존 ChatGPT 로그인,
[검토한 비공개 런타임 설정·이미지](../development/GENERATED_REPAIR_CONTRACT.md#승인형-복사본-흐름-실행)가
필요합니다. GUI에는 UI extra를 갖춘 editable 소스 설치와 프런트엔드 빌드가 추가로 필요합니다.
정적 목록·저장 결과 조회에는 모델 로그인이 필요하지 않습니다. 실행 파일은 서명·공증되지
않았으며 PyPI/npm 발행은 이번 절차에 포함하지 않습니다.

## 시연에서 밝혀야 할 한계

- AI 수정은 **유지 중인 합성 사례 하나**를 지원합니다. 정적 작업 공간 선택으로 그 저장소를
  전송하거나 수정하지 않습니다. 범용 FastAPI 수정·임의 대상 실행·독립 모델 비교 벤치마크는
  이번 판에 포함되지 않습니다.
- 소스 선언은 런타임 접근통제 증명이 아닙니다. 부분 분석·unknown·미실행을 구분하며 대조 항목
  통과가 앱 전체 보안을 증명하지 않습니다.
- GUI 활동은 호스트 단계이며 실시간 Codex 토큰 스트림이 아닙니다. 저장 JSON은 미검증 자료로
  가져오며 실행 권한이나 이전 실행 재개 권한을 주지 않습니다.
- 결정은 만료되고 한 번만 사용할 수 있습니다. 적용 후 취소하면 복구 작업이 남을 수 있으므로 실제
  복구·정리 상태를 확인하고 필요한 비공개 복구 파일을 보관하세요.
- 검토한 guest 제어에도 격리·가용성 한계가 있습니다.
  [워크플로 계약](../development/GENERATED_REPAIR_CONTRACT.md)과 [보안 정책](../SECURITY.md)을 참고하세요.
- 개발 포맷터의 후보별 경고·추적은 [#89](https://github.com/casing1/authzest/issues/89)와
  [#171](https://github.com/casing1/authzest/issues/171)에 유지합니다.
  [포맷터 근거](../development/FORMATTING.md)를 참고하세요. 이 노트는 위험 수용 결정이 아닙니다.

## 검증과 발행 상태

[#197](https://github.com/casing1/authzest/issues/197)은 소스 `80b574d`에서 한 macOS arm64
Python 3.12 호스트의 신규·기준판·업그레이드 CLI 검사 39/39개, 읽기 전용 UI 검사 7개,
세 OS의 [7개 작업 native preview](https://github.com/casing1/authzest/actions/runs/45111054819)를 기록합니다.
이것은 해당 소스의 사전 관찰이며 새로운 활성 AI 실행이나 최종 공개 파일이 아닙니다.
최종 문서 전달·근거 수용·도구 판단과 태그·공개 다운로드 검증은
[준비 상태](0.1.0-READINESS.md)와 [#150](https://github.com/casing1/authzest/issues/150)에서 추적합니다.
이전 관찰은 각각 기록된 소스에 귀속됩니다.

구현 이력은 [변경 이력](../CHANGELOG.md), 발행 조건은 [릴리스 절차](RELEASING.md)를 참고하세요.
